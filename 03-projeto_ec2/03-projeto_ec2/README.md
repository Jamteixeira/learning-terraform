# Infraestrutura web simples com terraform na AWS


## Objetivo
Este projeto demonstra a criação e o gerenciamento de uma infraestrutura em nuvem utilizando a abordagem de Infraestrutura como Código (IaC). O ambiente provisiona um servidor web (EC2) e configura as regras de segurança (Security Group) necessárias.

## Tecnologias utilizadas: 
* **Nuvem:** AWS (Amazon Web Services)
* **IaC:** Terraform
* **Versionamento:** Git e GitHub
